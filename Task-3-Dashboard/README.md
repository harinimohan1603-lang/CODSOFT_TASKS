# Task 3 – Data Visualization Dashboard

## Project Title
LinkedIn Job Analysis Dashboard

## Objective
To analyze LinkedIn job posting data and present meaningful insights through interactive visualizations.

## Tools Used
- Power BI
- Data Visualization
- LinkedIn Job Dataset

## Dashboard
The dashboard provides insights into:
- Job postings
- Unique companies
- Cities covered
- Application records
- Hiring companies
- Hiring cities
- Experience levels
- Work types
- Contract types
- Hiring sectors

## Key Insights
- 726 job postings were analyzed.
- 454 unique companies are represented in the dataset.
- 104 cities are covered in the dataset.
- Full-time jobs are the most common employment type.
- Bengaluru has the highest number of job postings.

## Outcome
An interactive Power BI dashboard was created to present the job market insights in a clear and easy-to-understand format.
